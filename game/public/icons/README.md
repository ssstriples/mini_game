# PWA 아이콘 안내

이 폴더에 아래 두 파일을 배치하세요:

| 파일명 | 크기 | 용도 |
|--------|------|------|
| `icon-192.png` | 192×192 px | 홈 화면 아이콘 (Android) |
| `icon-512.png` | 512×512 px | 스플래시 / 마스커블 아이콘 |

## 빠른 생성 방법 (무료 온라인 도구)

1. https://realfavicongenerator.net
   - 512×512 PNG 업로드 → 모든 크기 자동 생성
   - "Generate your Favicons" 클릭 후 다운로드

2. https://www.pwabuilder.com/imageGenerator
   - 1024×1024 PNG 업로드 → icon-192, icon-512 자동 생성

## 임시 아이콘 (개발용)

아이콘 없이 빌드하면 콘솔에 경고가 뜨지만 게임은 정상 작동합니다.
빌드 후 `dist/` 에 복사해도 됩니다.

## 권장 디자인

- 배경: #ff6b35 (주황)
- 아이콘: 🐿️ 다람이 또는 도토리 일러스트
- 여백: 아이콘 크기의 10% (마스커블 안전 영역 확보)
